# Cargo Dependency Visualizer

## Описание проекта

Инструмент для анализа и визуализации графа зависимостей
пакетов Rust (Cargo).

Проект выполняется в рамках практической работы
по дисциплине «Конфигурационное управление».

Вариант №32.

## Этапы разработки

1. Минимальный прототип с конфигурацией.
2. Получение данных о зависимостях пакетов.
3. Построение и анализ графа зависимостей.
4. Анализ обратных зависимостей.
5. Визуализация графа зависимостей.

## Этап 1. Минимальный прототип

Реализовано CLI-приложение на Python.

Программа загружает настройки из XML-файла,
проверяет их корректность и выводит на экран.

### Параметры конфигурации

- package_name — название анализируемого пакета.
- repository_url — URL удалённого репозитория.
- test_mode — режим работы с тестовым репозиторием.
- package_version — версия пакета.
- output_mode — режим отображения зависимостей.
- max_depth — максимальная глубина анализа.

### Запуск программы

```powershell
python src/main.py
```

Или на Windows:

```powershell
.\run.bat
```

### Запуск тестов

```powershell
python -m unittest discover -s tests -v
```
